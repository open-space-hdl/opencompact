# ocp_mib

Status interface of an OpenCompact channel: an AXI4-Lite slave with the identification, read-only registers with the
generics that define the compressed images, and 32-bit saturating counters of the images, of the faulty and discarded
SDUs and of the memory errors; a write to a counter clears it. The register map is generated by `tools/regmap.py` from
`regs/ocp_regs.yml`, together with the VHDL package `ocp_regs_pkg` and the C header `sw/ocp_regs.h`.
